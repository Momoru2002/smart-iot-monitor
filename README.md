# 🌐 Smart IoT Monitoring Dashboard

Modern IoT dashboard system for monitoring:

- Temperature
- Humidity
- Energy Usage
- Air Quality

## 🚀 Features

- Real-time dashboard
- Flask API backend
- Live sensor chart
- Responsive UI
- Smart monitoring system

## ⚙️ Tech Stack

### Backend
- Python
- Flask

### Frontend
- HTML
- CSS
- JavaScript
- Chart.js

## 🚀 Run

### Install Flask

pip install flask

### Start Backend

cd backend
python app.py

### Open Dashboard

Open:

frontend/index.html
